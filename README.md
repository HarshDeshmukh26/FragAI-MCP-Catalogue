# FragAI MCP Catalogue

Curated remote Model Context Protocol (MCP) server definitions for the [FragAI Governance Platform](https://github.com/HarshDeshmukh26/governance-platform).

The catalogue currently contains **166 remote MCP server entries**. It provides the metadata required to display, configure, and connect to provider-hosted MCP servers.

This repository contains catalogue definitions only. It does not contain, redistribute, deploy, or run the providers' MCP server implementations.

## Current scope

- Remote, provider-hosted MCP servers
- One root-level YAML file per catalogue entry
- User-friendly descriptions and setup guidance
- Authentication and endpoint configuration
- Tool previews where available
- Privacy, cost, write-action, and destructive-action warnings where relevant

Hosted, local, and system MCP servers are outside the current scope and should be reviewed separately before being added.

Never commit credentials, API keys, access tokens, OAuth secrets, or private endpoint information to this repository.
